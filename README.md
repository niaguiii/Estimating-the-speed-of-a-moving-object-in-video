# 动态场景移动物体速度估计系统 🎬

> **基于深度学习的单摄像头全自动速度估计系统 - 支持移动摄像头、多场景、全自动测速**

---

## 🎯 项目概述

### 📋 项目目标
开发一个**通用的动态场景物体速度估计系统**，核心创新在于**支持移动摄像头场景**：
- 🔍 **精确检测** - YOLOv8检测80+类物体（人、车、球等）
- 🎯 **稳定追踪** - ByteTrack高精度多目标追踪
- 📷 **移动摄像头支持** - RAFT光流分离摄像头运动与目标运动
- 📏 **全自动测速** - Metric Depth深度估计，无需手动标定
- 🌧️ **恶劣条件鲁棒** - 支持雨天、模糊、晃动等复杂场景

### 🌟 核心创新点

| 传统方案 | 本系统 |
|---------|--------|
| 假设摄像头固定 | ✅ 支持移动摄像头（车载、手持、无人机） |
| 需要手动标定 | ✅ Metric Depth全自动深度估计 |
| 仅输出像素速度 | ✅ 输出真实世界速度 (km/h, m/s) |
| 固定场景 | ✅ 多场景通用（交通、运动、监控） |

```

└─────────────────────────────┬───────────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────────────┐
│  检测层：YOLOv8                                                      │
│  输出：物体边界框 + 类别 + 置信度                                      │
└─────────────────────────────┬───────────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────────────┐

└─────────────────────────────┬───────────────────────────────────────┘
                              ▼

│  运动分离层：RAFT光流 (核心创新)                                      │
│  ┌─────────────────┐    ┌─────────────────┐                         │
│  │ 计算全图光流     │ →  │ 估计摄像头运动   │                         │

│                                  ▼                                   │
│  ┌─────────────────────────────────────────────────────────┐        │
│  │ 运动分离：目标真实速度 = 观测速度 - 摄像头速度            │        │

└─────────────────────────────┬───────────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────────────┐
│  深度估计层：Depth Anything V2 Metric (全自动标定)                    │

┌─────────────────────────────────────────────────────────────────────┐
```

## 📞 项目信息

### 📋 基本信息
- **项目类型**: FYP (Final Year Project) - 计算机视觉/深度学习应用
- **核心定位**: 动态场景单摄像头全自动速度估计系统
- **技术栈**: 
  - 检测: YOLOv8 (Ultralytics原生)
  - 追踪: ByteTrack (卡尔曼滤波 + 两阶段匹配) ✅
  - 速度: 物体尺寸估算 (简化版) ✅ → RAFT光流 (第三阶段)
  - 深度: Depth Anything V2 Metric (第三阶段)
- **开发状态**: 第一、二阶段完成，第三阶段开发中

### 🎯 FYP创新亮点
1. **移动摄像头支持** - 突破传统固定摄像头限制
2. **全自动深度估计** - 无需手动标定，Metric Depth自动完成
3. **运动分离算法** - RAFT光流分离摄像头与目标运动
4. **多场景通用** - 车载、运动、体育、无人机等场景

### 🙏 致谢
感谢以下开源项目和技术社区的支持：
