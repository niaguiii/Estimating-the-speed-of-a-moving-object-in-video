# 一、项目概述

## 📋 项目目标

开发一个**通用的动态场景物体速度估计系统**，核心创新在于**支持移动摄像头场景**：

- 🔍 **精确检测** - YOLOv8检测80+类物体（人、车、球等）
- 🎯 **稳定追踪** - ByteTrack高精度多目标追踪
- 📷 **移动摄像头支持** - RAFT光流分离摄像头运动与目标运动
- 📏 **全自动测速** - Metric Depth深度估计，无需手动标定
- 🌐 **Web界面** - Vue 3 + FastAPI，支持在线使用

---

## 🌟 核心创新点

| 传统方案 | 本系统 |
|---------|--------|
| 假设摄像头固定 | ✅ 支持移动摄像头（车载、手持、无人机） |
| 需要手动标定 | ✅ Metric Depth全自动深度估计 |
| 仅输出像素速度 | ✅ 输出真实世界速度 (km/h, m/s) |
| 固定场景 | ✅ 多场景通用（交通、运动、监控） |
| 仅命令行工具 | ✅ CLI模式 + Web界面双模式 |

# 二、功能与架构

## ✨ 核心功能

- ✅ **YOLOv8检测** - 80+类物体检测（人、车、卡车、自行车等）
- ✅ **ByteTrack追踪** - 卡尔曼滤波 + 两阶段匹配，追踪精度 80-90%
- ✅ **RAFT光流** - 摄像头运动分离，支持移动摄像头 (Phase 3)
- ✅ **Depth Anything V2** - 单目深度估计，自动深度感知标定 (Phase 3)
- ✅ **智能速度估算** - 深度感知 + RAFT补偿，输出精确 km/h (Phase 3)
- ✅ **轨迹可视化** - 渐变色轨迹线 + 速度统计面板
- ✅ **EMA平滑** - 速度显示稳定无闪烁
- ✅ **统一入口** - main.py 整合所有功能
- ✅ **Web界面** - Vue 3前端 + FastAPI后端，支持在线操作

## 🎮 五种处理模式详解

本系统提供**5种处理模式**，适用于不同场景和精度需求：

### 模式对比表

| 模式 | 名称 | 适用场景 | 精度 | 速度 | 特点 |
|------|------|----------|------|------|------|
| **模式1** | 检测+追踪 | 固定摄像头，仅需追踪 | ⭐⭐⭐ | 最快 | 基础追踪，无速度估算 |
| **模式2** | 速度估算 | 固定摄像头，需要速度 | ⭐⭐⭐⭐ | 快 | 基于物体尺寸估算速度 |
| **模式3** | RAFT光流 | 移动摄像头（手持、车载） | ⭐⭐⭐⭐ | 中等 | 分离摄像头运动 |
| **模式4** | 相对深度 | 移动摄像头+深度信息 | ⭐⭐⭐⭐ | 较慢 | 深度感知，±10-15% |
| **模式5** | 绝对深度 🔥 | 最高精度，通用场景 | ⭐⭐⭐⭐⭐ | 较慢 | 绝对深度，±2-5%，无需标定 |

---

### 模式详细说明

#### 模式1️⃣: 检测 + 追踪（ByteTrack）

**功能：**
- YOLOv8物体检测
- ByteTrack多目标追踪
- 追踪ID可视化
- 轨迹线绘制

**适用场景：**
- 固定摄像头监控
- 仅需要追踪轨迹，不需要速度
- 追求最快处理速度

**输出：**
- 带检测框和追踪ID的视频
- 物体轨迹可视化

---

#### 模式2️⃣: 速度估算（推荐日常使用）

**功能：**
- 模式1的所有功能
- **基于物体尺寸的速度估算**
  - 自动识别物体类型（车、人、卡车等）
  - 根据标准尺寸自动标定
  - 实时计算速度（km/h）
- EMA速度平滑
- 速度统计面板（最大速度、平均速度）

**适用场景：**
- 固定摄像头
- 需要速度信息
- 日常测速任务

**输出：**
- 模式1的所有输出
- 实时速度显示（km/h）
- 速度统计信息

**优点：**
- 速度快
- 无需手动标定
- 适合大部分场景

**局限：**
- 假设摄像头固定
- 基于物体标准尺寸，精度受限

---

#### 模式3️⃣: RAFT光流（核心创新）

**功能：**
- 模式2的所有功能
- **RAFT光流运动分离**
  - 计算全图光流场
  - 估计摄像头自身运动
  - 分离目标真实运动
  - 补偿摄像头运动

**适用场景：**
- **移动摄像头**（车载、手持、无人机）
- 摄像头晃动或移动的场景
- 需要准确速度的复杂场景

**输出：**
- 模式2的所有输出
- 补偿摄像头运动后的真实速度
- 光流可视化（可选）

**优点：**
- 支持移动摄像头 ⭐ 核心创新
- 自动分离摄像头运动
- 精度高于模式2

**技术原理：**
```
观测速度 = 摄像头运动 + 目标真实运动
         ↓
RAFT光流估计摄像头运动
         ↓
目标真实速度 = 观测速度 - 摄像头运动
```

---

#### 模式4️⃣: 相对深度感知（Depth Anything V2）

**功能：**
- 模式3的所有功能
- **Depth Anything V2深度估计**
  - 单目相对深度估计
  - 深度规一化（0-1范围）
  - 自动标定（基于物体尺寸）
- **基于深度的速度计算**
  - 结合深度信息优化像素-米比例
  - 深度修正的距离计算
  - 速度精度：±10-15%

**适用场景：**
- 移动摄像头 + 需要深度信息
- 中等精度需求
- 有一定计算资源

**输出：**
- 模式3的所有输出
- 深度图可视化
- 深度感知的速度估计

**优点：**
- 支持移动摄像头
- 深度信息增强精度
- 自动标定

**局限：**
- 输出相对深度，需要场景标定
- 精度受标定误差影响

---

#### 模式5️⃣: 绝对深度测速（Metric3D v2 - 最新最好！）🔥

**功能：**
- 模式3的所有功能
- **Metric3D v2绝对深度估计**
  - 单目绝对深度估计（直接输出米数！）
  - 无需场景标定（全自动！）
  - 结合相机内参（自动估算）
- **3D空间精确测速**
  - 2D像素 + 绝对深度 → 3D坐标
  - 3D空间距离计算
  - 真实世界速度输出
  - 速度精度：±2-5% ✨

**适用场景：**
- 最高精度需求
- 通用场景（不需每次标定）
- 移动摄像头 + 需要绝对距离
- 科研级应用

**输出：**
- 模式3的所有输出
- 绝对深度图（米）
- 3D空间速度估计
- 真实距离显示

**优点：**
- ✅ 输出绝对深度（米），不是相对值
- ✅ 无需场景标定（自动！）
- ✅ 适应所有场景（零样本泛化）
- ✅ 精度最高（±2-5%）
- ✅ 配合光流支持移动摄像头
- ✅ 3D空间速度，真实世界坐标

**技术原理：**
```
RGB图像 → Metric3D v2 → 绝对深度（米）
         ↓
2D像素 + 深度 → 3D坐标 (X, Y, Z)
         ↓
  3D距离 = sqrt((X2-X1)² + (Y2-Y1)² + (Z2-Z1)²)
         ↓
    速度 = 3D距离 / 时间
```

**模型选项：**
- `small` (~500MB) - 推荐，速度快
- `large` (~1.3GB) - 平衡，精度高
- `giant2` (~1.6GB) - 最高精度

**适用场景：**
- 需要最高精度
- 无法手动标定的场景
- 全自动测速系统

**输出：**
- 模式3的所有输出
- 深度图可视化（可选）
- 最高精度的速度数据

**优点：**
- **全自动标定** ⭐ 无需人工参与
- **最高精度** ⭐ 基于真实深度
- 支持移动摄像头
- 适应各种场景

**技术原理：**
```
1. Depth Anything V2估计每个像素的深度
2. 自动计算像素/米比例
3. 结合RAFT光流分离运动
4. 输出真实世界速度（km/h）
```
